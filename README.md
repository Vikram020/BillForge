# BillForge Flutter
Modern Invoice & Billing SaaS-style Flutter app.

Included:
- Dashboard
- Invoice list
- Create/edit invoice
- Live calculations and preview
- Clients
- Products & services
- Payments
- Reports
- Settings
- Search/filtering
- Light/dark theme
- GST-ready fields
- Responsive desktop/tablet/mobile UI

Run:
```bash
flutter pub get
flutter run
```

This build uses in-memory mock data. Add your API/database layer later.
